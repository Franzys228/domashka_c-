Задача 1: программа сравнивает округлённую формулу Бине с точными целыми
значениями последовательности для всех индексов, помещающихся в
unsigned long long. В текущем запуске g++ первый неверный индекс: float — 31,
double — 70. Эти пороги зависят от реализации стандартной библиотеки.

Задача 2: используется рекурсия x(i+1) = 108 - (815 - 1500/x(i-1))/x(i),
с x(0)=4 и x(1)=4.25. Проверка: float приходит к 100 за 13 шагов,
double — за 27 шагов. Фактический вывод сохранён в experiment_results.txt.

Задача 3: обе версии бинарного поиска работают за O(log n). Рекурсивный
вариант использует O(log n) стековых кадров; для int-индекса глубина мала
даже у практически недостижимых размеров массива, но итеративный вариант
не расходует стек.

Задача 4: полный перебор — O(n^2) времени и O(1) дополнительной памяти.
Для уже отсортированного массива два указателя дают O(n) времени.

Задача 5: перебираются все 2^N подмножеств с подсчётом каждого за O(N);
асимптотика O(N*2^N) времени и O(N) памяти на вход.
